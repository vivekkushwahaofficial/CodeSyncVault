# Code of Conduct

CodeSyncVault is an open-source browser extension built for developers. We welcome contributions from developers of all experience levels.

By participating in the CodeSyncVault project, you agree to maintain a respectful, professional, and constructive environment.

## Expected Behavior

Contributors and community members should:

- Communicate respectfully and professionally.
- Keep discussions constructive and focused on the project.
- Welcome different technical opinions and approaches.
- Provide useful and respectful feedback.
- Respect project maintainers and other contributors.
- Follow the project's contribution, licensing, security, and trademark policies.

## Unacceptable Behavior

The following is not acceptable:

- Harassment, discrimination, threats, or personal attacks.
- Deliberately disruptive or abusive behavior.
- Sharing private or sensitive information without permission.
- Introducing malicious code or intentionally harmful functionality.
- Attempting to compromise CodeSyncVault, its users, or connected services.
- Misrepresenting an independent fork as an official CodeSyncVault release.

## Security

Please report security vulnerabilities privately to the project maintainers rather than publicly disclosing them.

Do not include passwords, tokens, API keys, or other secrets in issues, pull requests, or commits.

## Enforcement

Project maintainers may remove inappropriate content, reject contributions, or restrict participation when this Code of Conduct is violated.

Serious or repeated violations may result in removal from the project.
